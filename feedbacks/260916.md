# Feedback (9/16/2026)

## Installing required packages

On a Mac OS X, we don't have `apt-get` by default.
Instead, I could do the following.

```
brew install --cask mactex-no-gui
eval "$(/usr/libexec/path_helper)"
```

Also, I found missing python packages like `PyYAML`, `seaborn`, etc.
Instead of installing them one by one, I wrote required packages in `requirements.txt` and run the following.

```
pip install -r requirements.txt
```

I'll open an issue for this and request to add `requirements.txt`.

## Typesetting

In the current `Makefile`, there is no specification of the LaTeX engine, which caused my computer to use `pdfTeX`, different from the assumed `LuaTeX`.
I fixed this with explicitly specifying the LaTeX engine in the corresponding line of `Makefile`.

```Makefile
latexmk -lualatex -bibtex -logfilewarnings -f -interaction=nonstopmode NUPAQIS
```
